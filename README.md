
# CodeAlpha Web Scraping Project

## Project Overview
This project collects book information from the Books to Scrape
website using Python web scraping techniques.

## Objectives
- Collect book titles, prices, ratings, and availability.
- Store scraped data in a structured dataset.
- Perform basic data quality checks.
- Analyze book prices and rating distributions.

## Tools and Libraries
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset Details
- Total records: 1000
- Total columns: 4
- Missing values: 0
- Duplicate rows: 0
- Unique titles: 999

## Columns
1. Title
2. Price_GBP
3. Rating
4. Availability

## Analysis
The project examines book price statistics,
rating distributions, and availability.

## Files
- books_dataset.csv: Scraped book dataset
- analysis_report.txt: Analysis report
- CodeAlpha_Web_Scraping.ipynb: Python notebook

## How to Run
1. Download the notebook.
2. Open it in Google Colab.
3. Run the cells in order.
